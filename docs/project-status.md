# NumDock 功能盘点

当前版本提供可运行、持久化的 **Mock 开发版**。未接入真实运营商或支付机构，不作为生产通信服务。

| 模块 | 当前可用行为 |
| --- | --- |
| 身份与账户 | 注册登录、Argon2id、12 小时 Cookie 会话、CSRF、持久限流、内部归属隔离与角色校验 |
| 号码目录与租约 | 数据库目录筛选／排序／分页、用途确认、30 天独占租约、申请、释放、到期、5 分钟号码隔离 |
| 订单 | 幂等创建、并发防重复分配、模拟供应商失败及资金补偿、订单查询与退款 |
| 消息 | 号码页模拟入站、签名供应商回调、事件去重及异常隔离、加密正文、已读、删除、30 天保留、访问审计 |
| 账单 | USD 美分钱包、Mock 充值、资金预留／结算／释放、退款、不可修改的账本 |
| 实时与任务 | River 事务入队、到期与清理任务、SSE 元数据事件及 Last-Event-ID 恢复 |
| 概览 | 当前余额与业务计数、独立标注的 30 天历史演示图表、OpenTelemetry traces／metrics、可选 Grafana 看板 |
| API 契约 | OpenAPI、生成的 TypeScript 客户端、独立资源接口、统一错误与 Request ID |

Mock 功能只在 `APP_ENV=development` 启用；生产环境关闭模拟目录与业务写入。管理员／所有者可写业务，普通成员可读组织号码、消息和账单。

开发与体验步骤见 [开发数据](development-data.md)，业务规则及接口例子见 [Mock 工作区](mock-workspace.md)。

正式上线仍需独立完成真实供应商与支付授权、适配及联调，邮箱验证和账户恢复、成员邀请与管理、运营合规审核、备份恢复、容量和生产部署验收。开发版的模拟充值、退款和免费收信规则不代表真实渠道条款。

## 公开页面与会话同步

新增公开 `GET /v1/status`，报告 API／数据库就绪状态、身份／目录／号码／消息／账单功能模式，以及真实供应商和支付渠道的接入标识；不含组织或用户数据。它作为基础设施保留，产品不再提供技术状态展示页。开发模式使用 Mock，生产模式保持这些业务功能禁用；数据库不可用时报告异常。

首页、安全页与工作区共享集中管理的 identityQuery 和账户菜单；401 清空已登录身份为匿名，网络错误单独提示重试，登录成功写入身份缓存，退出撤销会话并清空缓存。公开 HTML 不嵌入用户身份，浏览器刷新后通过 HttpOnly Cookie 查询恢复。


## 公开选购与组织地址

首页公开展示数据库中可用号码及月费、短信接收单价，共用 TanStack Query 缓存与 TanStack Table 筛选、排序、分页。公开目录只返回 available 库存，排除已租用和隔离号码；不会公开组织已租号码、余额或消息。游客选择号码后，在申请步骤登录／注册并保留号码筛选，确认用途、价格后才创建订单；工作区继续要求认证。开发页仅保留一处样本目录说明；真实供应商和支付尚未接入。

组织持久化唯一 slug，注册时按组织名生成并附随机后缀区分重名，修改名称不会改变 slug。浏览器导航使用 ?organization=numdock-development 等可读地址；旧 UUID 查询地址认证后重定向并保留其他查询参数。API 仍按内部组织 ID 执行成员授权，不以 slug 作为权限凭据。无权限的组织地址返回 404，不自动切换到其他组织。


## 个人账户与支付订单

普通用户界面已移除组织选择、组织成员表、注册组织名称、开发者导航和 API 文档入口；新账户使用姓名创建内部隔离边界，历史租户数据和成员授权保持兼容。默认账户导航不再自动追加 organization 查询参数，旧组织短名称地址仍受原权限保护。

充值界面不再直接调用 mock-credit：先创建持久支付订单，再确认支付；只有 succeeded 状态才写入一次 payment_credit 账本。支持待支付恢复、取消、失败、15 分钟过期、分页历史、并发确认及响应丢失重试。River 负责可靠超时任务，读路径和确认路径同时校验截止时间。真实支付渠道仍未选择，目前仅有开发支付，不处理真实资金或银行卡信息。接口说明见 backend/openapi/payments.md。


## 资源接口与集中 Query hooks（0.9）

产品已删除平台技术介绍、状态展示、交互 API 文档、开发者页面和概览中的 OpenTelemetry 技术卡片。API Key 与用户外发 Webhook 的接口、实现和样本生成已移除；历史表保留，旧投递任务不再发送网络请求。供应商入站验签、SSE、后台任务和观测属于业务基础设施，继续保留。

旧 /workspace?view=... 聚合接口已移除。号码、消息、订单、余额、余额明细、支付记录分别使用独立资源路径；列表只返回 items 与分页信息，概览摘要不携带列表数据。每个端点继续执行账户授权。OpenAPI 已同步，前端传输类型重新生成。

所有 TanStack Query hooks、queryOptions、查询键、重试与缓存失效集中在 frontend/app/hooks/api，组件保留表单和展示状态。SSE 按资源事件失效关联查询，消息关闭时清理正文缓存。ESLint 阻止组件绕过这一目录重新声明 Query hooks。
