# NumDock 功能盘点

当前版本提供可运行、持久化的 **Mock 开发版**。未接入真实运营商或支付机构，不作为生产通信服务。

| 模块 | 当前可用行为 |
| --- | --- |
| 身份与组织 | 注册登录、Argon2id、12 小时 Cookie 会话、CSRF、持久限流、组织隔离与角色校验、组织上下文切换 |
| 号码目录与租约 | 数据库目录筛选／排序／分页、用途确认、30 天独占租约、申请、释放、到期、5 分钟号码隔离 |
| 订单 | 幂等创建、并发防重复分配、模拟供应商失败及资金补偿、订单查询与退款 |
| 消息 | 号码页模拟入站、签名供应商回调、事件去重及异常隔离、加密正文、已读、删除、30 天保留、访问审计 |
| 账单 | USD 美分钱包、Mock 充值、资金预留／结算／释放、退款、不可修改的账本 |
| 开发者 | 限定组织与权限的 API Key、1–90 天有效期、一次性展示与撤销、加密 Webhook 密钥、端点启停、测试投递与记录 |
| 实时与任务 | River 事务入队、到期与清理任务、Webhook 最多 5 次投递、SSE 元数据事件及 Last-Event-ID 恢复 |
| 概览 | 当前余额与业务计数、独立标注的 30 天历史演示图表、OpenTelemetry traces／metrics、可选 Grafana 看板 |
| API 契约 | OpenAPI、生成的 TypeScript 客户端、Scalar 文档、统一错误与 Request ID |

Mock 功能只在 `APP_ENV=development` 启用；生产环境关闭模拟目录与业务写入。管理员／所有者可写业务，普通成员可读组织号码、消息和账单。密钥／端点管理需要浏览器管理员会话。

开发与体验步骤见 [开发数据](development-data.md)，业务规则及接口例子见 [Mock 工作区](mock-workspace.md)。

正式上线仍需独立完成真实供应商与支付授权、适配及联调，邮箱验证和账户恢复、成员邀请与管理、运营合规审核、备份恢复、容量和生产部署验收。开发版的模拟充值、退款和免费收信规则不代表真实渠道条款。

## 后端接口后续缺口（按当前代码核对）

以下为后续需求清单，不表示已有对应路由：

| 范围 | 尚未实现 |
| --- | --- |
| 账户 | 修改资料／密码、邮箱验证、找回密码、会话列表与撤销其他会话 |
| 组织 | 独立创建／修改组织、成员邀请、成员列表管理、角色修改、移除成员 |
| 号码与订单 | 独立号码／订单／租约详情、续租、暂停／封禁、真实供应商库存与生命周期同步 |
| 计费 | 真实支付与验签回调、支付订单、发票、自动充值、供应商成本、对账；目前仅 USD Mock 钱包 |
| 开发者 | 密钥轮换、Webhook URL 修改／删除及 secret 轮换、失败投递的人工重放、组织套餐／月度 API 配额 |
| 运营 | 平台管理员 API、审核／投诉处理、隔离消息处置、审计记录查询与导出 |

已有列表通过组织下的 `/workspace?view=...` 提供；不能将没有独立 `/numbers` 或 `/orders` GET 路由误认为没有号码或订单查询。密钥／端点固定上限已在事务内串行校验，避免并发越限。`resource_limit`、`invalid_webhook_url`、`webhook_disabled` 已补齐错误契约与翻译。

OTLP 已有 HTTP/protobuf traces、metrics 导出与接收测试；尚需运行采集服务并验证实际 Grafana 链路，补数据库／业务／River／出站请求观测、日志导出、采样与资源控制、告警及导出健康状态。SDK 支持标准采样环境变量，但开发脚本尚未从 env 文件加载这些变量；可先通过进程环境设置，不能把它描述成 SDK 不支持采样。

## 公开页面与会话同步

新增公开 `GET /v1/status`，报告 API／数据库就绪状态、身份／目录／号码／消息／账单／开发者功能模式，以及真实供应商和支付渠道的接入标识；不含组织或用户数据。公开页 SSR 与 TanStack Query 消费生成契约，不再把业务模块状态写死为未接入。开发模式使用 Mock，生产模式保持这些业务功能禁用；数据库不可用时报告异常。

首页、平台页、安全页、状态页与工作区共享 identityQuery 和账户菜单；401 清空已登录身份为匿名，网络错误单独提示重试，登录成功写入身份缓存，退出撤销会话并清空缓存。公开 HTML 不嵌入用户身份，浏览器刷新后通过 HttpOnly Cookie 查询恢复。
