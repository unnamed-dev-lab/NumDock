# NumDock 功能盘点

以当前仓库实现为准，页面存在不等于完整业务已实现。当前可用于本地身份流程和模拟目录开发，不是完整生产产品。

| 领域 | 已实现 | 仍需完善 |
| --- | --- | --- |
| 身份 | PostgreSQL 注册、Argon2id 密码、登录、12 小时 Cookie 会话、CSRF、持久限流、退出 | 邮箱验证、密码找回、资料修改、列出及撤销其他会话 |
| 组织 | 注册创建 owner、当前用户组织列表、组织成员角色读取与隔离 | 组织切换上下文、邀请、成员／角色管理及审计 |
| 号码目录 | 登录后只读查询，服务端搜索、筛选、排序、分页、匹配总数；开发模式模拟数据 | 真实供应商授权、报价同步、库存时效、合规限制 |
| 用户号码／租约 | 未接入的空状态页面 | 原子分配、独占租约、生命周期、释放与补偿 |
| 订单 | 路由兼容跳转到账单页面，无订单业务 | 订单状态机、Idempotency-Key、失败补偿和可靠超时 |
| 短信 | 未接入的空状态页面 | Webhook 验签去重、有效租约匹配、加密保存、租户隔离、留存和访问审计 |
| 计费 | 未接入的空状态页面，无真实余额 | 支付、钱包、资金预留、不可变账本、退款及对账 |
| 开发者 | Scalar 文档、OpenAPI 契约、生成的 TypeScript 类型 | API Key、业务 API 权限与 Webhook 配置 |
| 实时与后台任务 | 未实现 | River 持久任务、SSE 重连及断线恢复 |
| 运营及合规 | 边界约定与说明页面 | 供应商授权记录、用途声明、审核、投诉、停用和审计工作流 |
| 公开页面与国际化 | 首页、平台、安全、服务状态、文档；英文／简体中文 | 公开页 SEO／SSG 完整验收、生产环境部署验收 |
| 工程 | Goose、sqlc、OpenAPI、Go 测试、Playwright、Lint、类型检查与构建脚本 | 交易并发／幂等测试、可观测性、备份恢复、负载与生产部署验证 |

## 本次完成的切片

- 新增 `GET /v1/catalog/numbers`，统一错误结构与 Request ID，要求有效会话。
- 使用数据库存储目录及整数价格；列表和总数在同一个只读一致性快照内查询。
- `APP_ENV=development` 才显示 `mode=mock`；其他环境返回 `mode=disabled` 和空数据。
- 显式 seed 命令创建 4 个开发用户、2 个组织、24 条模拟记录；与迁移分离，可重复执行，不重置密码或覆盖记录。
- 前端移除写死的库存、真实供应商品牌、余额及第三方验证码能力声明，改用契约生成类型及 TanStack Query；筛选、排序、分页和目录标签放入 URL。

## 后续接口实施顺序

1. **号码业务闭环**：先建立授权 Mock Provider Adapter，再落地订单创建／查询和租约申请／释放；所有写操作由后端校验组织、对象归属、用途和幂等键。
2. **消息闭环**：持久化 Webhook 原始事件、去重、租约匹配、消息隔离与加密；随后接入 River 和 SSE。
3. **资金闭环**：整数金额、币种、资金预留、不可变账本、支付回调验签与幂等、退款及对账。
4. **身份与运营**：资料修改、邮箱验证／找回、成员邀请与授权、API Key 管理及操作审计。
5. **上线条件**：有明确授权与正式文档的真实供应商适配、合规流程、生产部署、可观测性及容量验证。

每一步同时更新 OpenAPI、生成客户端，并完成数据库集成测试。尚未实现的接口不在契约中宣称可用。
