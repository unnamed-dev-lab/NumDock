# Third-party UI source

`app/components/ui/{button,input,label,dropdown-menu}.tsx` was installed from the official [shadcn/ui registry](https://ui.shadcn.com/) using shadcn CLI 4.21.0. Project adaptations use the local `cn` helper, semantic color tokens, and reduced decoration. Interaction primitives are provided by Radix UI.
